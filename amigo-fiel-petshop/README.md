# Amigo Fiel Pet Shop

## Sobre o projeto

Projeto acadêmico de modelagem e implementação de banco de dados para um Pet Shop, desenvolvido utilizando MySQL 8.0.

O sistema contempla o gerenciamento de clientes, animais, funcionários, serviços, agendamentos, atendimentos, produtos, fornecedores, vendas, pagamentos e estoque.

## Tecnologias utilizadas

- MySQL 8.0
- MySQL Workbench
- SQL

## Estrutura dos arquivos

- 01_estrutura_mysql.sql — Criação do banco e das tabelas.
- 02_dados_exemplo_mysql.sql — Inserção de dados de exemplo.
- 03_consultas_mysql.sql — Consultas SQL.
- 04_regras_mysql.sql — Triggers e regras de negócio.

## Ordem de execução

1. 01_estrutura_mysql.sql
2. 04_regras_mysql.sql
3. 02_dados_exemplo_mysql.sql
4. 03_consultas_mysql.sql

Atenção: o primeiro script contém comandos DROP TABLE. Execute somente em ambiente de teste ou após realizar backup.

## Objetivo

Aplicar conceitos de modelagem de dados, relacionamentos, chaves primárias, chaves estrangeiras, consultas e integridade de dados.
