# Arquivos reunidos

Este pacote consolida os projetos distintos encontrados nos ZIPs disponíveis:

- `Trabalho para github.zip`: trabalho original de catálogo e imagens.
- `portfolio-ads-bruno-completo.zip`: catálogo atualizado, portfólio web, C, Python, Java e SQL.
- `projetos-ads-completo.zip` e `portfolio-github-profissional.zip`: versões anteriores dos mesmos projetos; os arquivos duplicados foram consolidados.
- `Trabalho em dupla teste - Copia.zip`: cópia adicional do trabalho original, preservada em `catalogo-fixadores/copia-original/`.

As versões originais do catálogo foram mantidas separadas da versão atualizada.
