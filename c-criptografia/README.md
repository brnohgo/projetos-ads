# Criptografia e Progressão Aritmética

Programa de terminal em C com menu para codificar e decodificar mensagens pela cifra de César e gerar os termos e a soma de uma progressão aritmética.

Compile com um compilador C compatível com C11, por exemplo: `gcc -std=c11 -Wall -Wextra -pedantic main.c -o estudos-c`.
