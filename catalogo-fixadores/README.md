# Catálogo de Fixadores

Projeto iniciado em uma atividade da faculdade para apresentar parafusos e arruelas usando HTML e tabelas. A versão atual mantém a proposta e as imagens do trabalho, com layout responsivo, pesquisa por texto e filtros por categoria.

- `index.html`: estrutura da versão atualizada.
- `style.css`: estilos e adaptação para diferentes telas.
- `script.js`: pesquisa, filtros e contagem de resultados.
- `assets/`: imagens utilizadas na versão atualizada.
- `trabalho-original/`: arquivos recebidos no ZIP original, preservados sem alterações.
- `copia-original/`: arquivos recebidos no ZIP de cópia, preservados sem alterações.

As especificações técnicas são demonstrativas e devem ser conferidas em documentação técnica antes de qualquer uso industrial.
